# Synthetic Hindi audio

All `s01`–`s12` WAV files are **Synthetic demo data** generated by Gemini TTS, not recordings of real patients or ASHA workers. Each same-name JSON contains the spoken script, expected route fields, TTS model, and duration. `generate_synthetic.py` is the source for the scripts. Each clip is shorter than 20 seconds.

Run `PYTHONPATH=. .venv/bin/python -m eval.audio_eval` from `backend/` to score them through the live voice route. Relative date words are accompanied by spoken September dates; `attempted_date` gold labels use 2026. The exact attempted time is not scored.
