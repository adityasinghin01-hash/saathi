# Saathi demo video — 3:30 shot list

Record a single synthetic Ramesh case through the real screens. Before recording, start the backend with `DEMO_MODE=1`, the frontend with `NEXT_PUBLIC_DEMO_MODE=1`, and check the browser connection. Reset the demo **once**, before the first take, on `/login` with `reset-demo`. Use the ASHA voice path for the case, then continue with pharmacist, district officer, and patient roles. Do not reset midway. Keep the **Synthetic demo data** badge visible; label the voice playback **Synthetic Gemini TTS (`s01.wav`)**. Use the [ASHA browser story](../frontend/e2e/voice-asha.spec.ts) and [full case story](../frontend/e2e/ramesh.spec.ts) as the interaction references.
